# Contributing

Thank you for helping grow Telugu-English Quotes.

## Add a quote
1. Choose the closest category file in `quotes/`.
2. Add a new JSON object to its array.
3. Use a unique ID with the category prefix (for example, `MEM004`).
4. Include Telugu, a faithful English meaning, and readable Telugu transliteration.
5. Add a mood and a few useful tags.
6. Check the JSON syntax and make sure the quote is not already present.

## Required fields
- `id`: unique stable identifier
- `category`: category slug
- `telugu`: original Telugu quote
- `english`: natural English meaning
- `transliteration`: Telugu written using English letters
- `mood`: short mood label
- `tags`: array of lowercase tags

## Editorial guidelines
- Submit original writing or material you have permission to share.
- Do not copy film lyrics, book passages, or another creator's quotes.
- Keep the language respectful and the translation emotionally accurate.
- Avoid personal information and targeted harassment.
